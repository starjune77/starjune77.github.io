# Junyoung Oh — Personal Portfolio

Interactive personal portfolio for Junyoung Oh. Live: https://starjune77.github.io

## Features

- Project laboratory, category filters, and detailed project dialogs
- Recruiter Quick View (`Q`), Developer Mode (`D`), and optional terminal (backtick)
- Clearly labeled study-planning, security-question, and vision simulations
- Responsive layouts, keyboard navigation, and reduced-motion support

## Technology

Semantic HTML, CSS, and JavaScript ES modules. No build process, runtime libraries, backend, camera access, or API keys.

## Preview

Serve this directory with a static HTTP server (ES modules require HTTP), for example `python -m http.server 8000`, then open http://localhost:8000. Deploy the files directly to GitHub Pages.

## Remaining assets

Place the real resume at `assets/resume/Junyoung_Oh_Resume.pdf`, then set `resumeAvailable = true` in `script.js` to activate its links. No PDF is fabricated. Add verified project repository URLs to `js/data.js` when available; currently only the supplied GitHub profile is linked.
